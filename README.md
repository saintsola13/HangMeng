# HangMeng 🎮

Neon Hangman game with West Coast vibes.

## Features
- **Solo mode** – pick a category (Animals, Movies, Food, Sports, Tech, Nature) or go Random
- **Two Player** – create a secret word, generate an invite code, share it
- **Copy button** for the invite code
- Neon glow UI, mobile-friendly

## How to play Two Player
1. One person hits **Two Player → Create Game**
2. Type a secret word (+ optional hint)
3. Hit **Generate Invite Code**
4. Copy the code and send it to a friend
5. Friend opens the game → **Join with Code** → pastes it and starts guessing

Pure frontend – no server needed. The code encodes the word so you can share it anywhere.

## Play
Open `index.html` in any browser, or turn on GitHub Pages.
